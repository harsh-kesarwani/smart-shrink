# Smart Shrink

A lightweight Django dashboard for Kubernetes downscaling recommendations and
estimated monthly cost savings, based on Prometheus CPU and memory metrics.
It provides recommendations only; it does not change running services.

## Prerequisites

- Python 3 with `pip` and `venv`.
- For refreshing metrics: network access to the configured Prometheus endpoint
  and valid credentials.

## Run locally

```bash
git clone https://github.com/harsh-kesarwani/smart-shrink.git
cd smart-shrink
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py runserver
```

Open http://127.0.0.1:8000/services/.

The dashboard reads the existing `results.json`; Prometheus access is not needed
to view it. Use the development server for local use only.

## Refresh metrics

Configure each service section in `config.ini` with its application and container
names, namespace, environment, comma-separated regions, Prometheus host, and
credentials. Do not commit credentials.

In another terminal, starting from the repository root:

```bash
source venv/bin/activate
cd scripts
python refresh_data.py
```

Run the refresh script from `scripts/`, since its file paths are relative to that
directory. It queries the last seven days of metrics, uses 95th-percentile
utilization for recommendations, and overwrites `results.json` with results
sorted by estimated monthly savings. Reload the dashboard after it finishes.

Savings are estimates based on fixed CPU and memory rates in the script, not
actual billing data. Review recommendations before making scaling changes.

## Repository layout

- `scripts/refresh_data.py`: configuration loading, recommendations, and savings.
- `scripts/prometheus_client.py`: Prometheus queries and metric helpers.
- `dashboard/`: dashboard view and routes.
- `dashboard/templates/dashboard/service_list.html`: namespaced dashboard template.
- `smart_shrink/`: Django settings and project routes.
- `config.ini`: service and Prometheus configuration.
- `results.json`: dashboard data generated by the refresh script.
